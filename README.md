# Python Calculator

A small calculator that runs in your terminal. Plain Python, no dependencies, and it keeps going until you tell it to stop.

## Getting started
You'll need Python 3 installed. If you don't have it yet, get it from [python.org](https://www.python.org/downloads/).

Then clone the repo and run it:

```bash
git clone https://github.com/curioushiva/python-calculator.git
cd python-calculator
python calculator.py
```

There's nothing else to install.

## Using it
Pick an operation from the menu, enter two numbers, and it prints the result. You can add, subtract, multiply, divide, or find the modulus. Choose 6 to quit.

```
<==== Simple python calculator ====>

1. Addition
2. Substraction
3. Multiplication
4. Divison
5. Modulus
6. Exit
```

## Notes
- Dividing by zero shows an error message instead of crashing.
- Typing something that isn't a number will stop the program for now, so stick to digits.
